# Project Overview

## Goal
Build a personal JARVIS assistant that understands voice and text commands, remembers tasks and useful knowledge, works with Google services, and safely uses approved tools.

## Confirmed preferences
- Hybrid deployment.
- Voice input and voice output.
- Google account for mail and calendar.
- Mixed permissions.
- Local durable memory on Windows.
- Obsidian as the human-readable knowledge base.
- Extensible modules and workflows.

## Product principles
1. Local-first for private data and memory.
2. Modular adapters rather than one monolithic agent.
3. Clear permission boundary for every tool.
4. Never claim an integration is connected until tested.
5. Every external side effect is auditable.
