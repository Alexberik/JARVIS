# Security Rules

- Never commit `.env`, API keys, OAuth tokens, or personal data.
- Keep the local service on `127.0.0.1`.
- Do not expose Obsidian Local REST API outside localhost.
- Unknown MCP tools are denied.
- Every approval is action-specific, parameter-specific, expiring, and one-time.
- Browser and desktop automation remain disabled until isolated and tested.
- No unrestricted shell execution.
- Never send email, publish posts, modify calendar events, purchase, trade, or delete files without explicit approval.
