# Проект JARVIS AI

## Цель
Локально-ориентированный персональный ассистент с веб-панелью, голосовым вводом/выводом, памятью на компьютере, Obsidian и расширяемыми интеграциями.

## Подтверждённые решения
- Размещение: hybrid (локальное ядро + веб-интерфейс).
- Голос: ввод и вывод.
- Почта и календарь: Google.
- Разрешения: смешанные; чувствительные внешние действия требуют подтверждения.
- Знания: Obsidian.
- Операционные задачи и память интерфейса: SQLite локально.

## Текущий baseline
- [x] Локальный HTTP-сервер и тёмная веб-панель
- [x] SQLite API для задач и памяти
- [x] Правильная маршрутизация CSS и JavaScript
- [x] Локальный статус Obsidian
- [ ] Проверка соединения с реальным vault
- [ ] GPT и Google OAuth
- [ ] Offline STT/TTS
