# JARVIS — Memory

Долговременная база знаний. Храни здесь только полезные, проверенные и актуальные сведения.

## Принципы
- Указывай источник и дату, если факт может устареть.
- Отделяй факт от предположения.
- Не сохраняй пароли, API-ключи, токены и секреты.
- Удаляй устаревшие сведения после проверки.
- Персональные заметки остаются в локальном vault и не публикуются в GitHub.
