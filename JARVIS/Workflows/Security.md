# Правила безопасности

- Не коммить `.env`, `config/settings.json`, API keys, OAuth tokens, базы данных и личные заметки.
- Локальный сервер слушает только `127.0.0.1` или `localhost`.
- Не публикуй Obsidian Local REST API в интернете.
- Неизвестные инструменты запрещены по умолчанию.
- Отправка почты, публикация, изменение календаря и финансовые действия требуют отдельного подтверждения.
- Shell execution, desktop control, торговля и удалённый доступ отключены до отдельного проектирования и тестирования.
- Не считай действие выполненным, пока инструмент не подтвердил результат.
