# Интеграции JARVIS

Статус указывается только после фактической проверки. Планируемые интеграции не считаются подключёнными.

| Интеграция | Статус | Следующий шаг |
|---|---|---|
| Web cockpit | Работает локально | Развивать визуальный интерфейс |
| SQLite | Работает локально | Продумать синхронизацию с Markdown |
| Obsidian filesystem | Основной режим | Проверить правильный vault и запись заметок |
| Obsidian Local REST API | Не требуется для текущего режима | Использовать только при отдельной необходимости |
| Browser SpeechRecognition | Зависит от Chrome/Edge | Улучшать голосовые команды |
| Browser SpeechSynthesis | Зависит от браузера и установленных голосов | Озвучивать ответы JARVIS |
| OpenAI / другие AI | Не подключены | Добавить провайдерный адаптер |
| Gmail | Не подключён | OAuth, поиск и черновики |
| Google Calendar | Не подключён | OAuth, чтение и создание событий с подтверждением |
| Weather | Команда ядра | Добавить понятные ответы и настройки города |
| MCP tools | Планируется | Allow-list и policy engine |
| Offline STT/TTS | Планируется | Локальные модели и runtime |
| n8n | Планируется | Подключать для отдельных автоматизаций |

## Принцип подключения

1. Сначала определить задачу и минимальные разрешения.
2. Секреты хранить только в локальной конфигурации или менеджере секретов.
3. Для внешних действий использовать режим предварительного просмотра и подтверждения.
4. Записывать результат и ошибки в [[../Log|журнал]].
5. Не объявлять интеграцию работающей до реального теста.
