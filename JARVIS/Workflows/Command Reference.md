# Команды JARVIS

Команды текущего rule-based режима (без свободного GPT-диалога):

| Команда | Действие |
|---|---|
| `статус` | Состояние Obsidian и конфигурации |
| `список заметок` | Список Markdown-файлов vault |
| `найди <текст>` | Поиск по заметкам |
| `прочитай <путь>` | Чтение заметки |
| `запиши в JARVIS/Log.md: текст` | Создать/перезаписать заметку |
| `добавь в JARVIS/Log.md: текст` | Дополнить заметку |
| `задачи` | Показать задачи из Obsidian |
| `добавь задачу <текст>` | Добавить задачу в Obsidian |
| `погода` | Погода для города по умолчанию |
| `время` | Локальное время |
| `помощь` | Справка |

Веб-панель также поддерживает отдельный SQLite список задач и память.
