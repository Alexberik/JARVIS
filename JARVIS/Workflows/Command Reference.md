# Команды JARVIS

Команды текущего rule-based режима (свободный GPT-диалог пока не подключён). Все пути к заметкам задаются относительно корня открытого vault — папки `JARVIS`.

| Команда | Действие |
|---|---|
| `статус` | Состояние Obsidian и конфигурации |
| `список заметок` | Список Markdown-файлов vault |
| `найди <текст>` | Поиск по заметкам |
| `прочитай Memory.md` | Прочитать заметку |
| `запиши в Log.md: текст` | Создать или перезаписать заметку |
| `добавь в Inbox.md: текст` | Дополнить заметку |
| `задачи` | Показать задачи из SQLite-хранилища веб-панели |
| `добавь задачу <текст>` | Добавить задачу в SQLite-хранилище |
| `погода` | Погода для города по умолчанию |
| `время` | Локальное время |
| `помощь` | Справка |

**Важно:** задачи и память, создаваемые в веб-панели, пока хранятся отдельно в SQLite. Они автоматически не синхронизируются с Markdown-файлами `Tasks.md` и `Memory.md` в Obsidian.
